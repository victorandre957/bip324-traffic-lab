Noise Generator deployed!

  Server pod : noise-http-server   (HTTP server, port 8080, random-sized responses)
  Client pod : noise-http-client   (continuous GET+POST requests to noise-http-server)

  Streaming UDP:
    server : noise-streaming-server (UDP 5000, steady small packets)
    client : noise-streaming-client

  Local Tor:
    server : noise-tor-da (TCP 9001/9030)
    client : noise-tor-client

  BitTorrent:
    server : noise-torrent-server (TCP 6881, libtorrent seeder)
    client : noise-torrent-client

Watch traffic:
  kubectl logs -n {{ .Values.namespace }} noise-http-server -f
  kubectl logs -n {{ .Values.namespace }} noise-http-client -f
